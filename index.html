👋 What this is

Private source for the foundation’s public changelog — a plain-language, dated record of what’s shipped across iamoneself.com and David Amaringo’s site, plus a /library of deeper technical write-ups for anyone curious how it’s all built. Written for someone outside the foundation who cares about the work, not for the team who already knows the context.

This README is also rendered as the live site’s own homepage.

🗂️ What’s here

  • changelog/ — one markdown file per entry, YYYY-MM-DD-short-slug.md.
  • library/ — deeper, standalone technical docs that don’t belong to one changelog entry.
  • teachings/ — a teacher’s own material, in a room of its own (today, Kenney’s Plants & Miracles, quoted exactly as printed). Served at /teachings; see LICENSE-CONTENT for its terms.
  • astro/ — the Astro site itself.
  • ROADMAP.md and SUSTAINABILITY.md — where this is headed, and what keeps it running. Each is also a page on the site (/roadmap, /sustainability).
  • .github/workflows/sync-public.yml — builds and syncs the compiled site (no source) to theholyearthfoundation/changelog-astro-public on every push to main.

Built on the fleet-wide pattern documented at my-template/changelog-template/README.md — read that first, it’s the actual spec (frontmatter schema, the confirmed-done-goes-straight-to-changelog convention, the org-vs-personal push-target rule).

✍️ Adding an entry

New file in changelog/, filename YYYY-MM-DD-short-slug.md:

---
title: "Plain-language title"
date: "YYYY-MM-DD"
priority: "P1-high" # or P2-medium (default), P3-low
repo: "iamoneself" # which project this entry belongs to
who: "Christopher W" # first name + last initial; see PEOPLE in astro/src/lib/people.ts
---

If something can’t be described publicly, it just doesn’t get an entry — the private technical record (each site’s own PENDING-TASKS.md/AGENT-SYNC docs) stays exactly where it already is.
