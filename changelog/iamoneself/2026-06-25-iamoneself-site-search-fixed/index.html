Site search now actually works

TL;DR: Search silently didn't work at all before this fix — now it does, on every page.
Read the full story →

The site’s search box looked normal but never returned results. The real cause, and the deeper technical write-up, lives in the library — the Pagefind ES-module fix.

What changed

  • Search now works across the whole site.

Why it mattered

A search box that silently does nothing is worse than no search box at all — it looks like it should work, so a visitor assumes their query just didn’t match anything, when actually nothing was searched at all.
